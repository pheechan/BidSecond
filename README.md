# BidSecond
**Access Here!** http://bidsecond.infinityfreeapp.com/public/register.php

**BidSecond** is a web-based second-hand item auction platform where users can register, list items, place bids, and compete in real-time to win unique finds. The project is built using mainly PHP and MySQL.

## Features

- User registration and login system (with OTP verification)
- Post and browse second-hand items
- Real-time bidding system
- Balance update
- User/Admin dashboard with bidding history, etc.
- Secure password hashing

## Tech Stack

- **Frontend**: HTML, CSS, JavaScript
- **Backend**: PHP
- **Database**: MySQL (via phpMyAdmin)
- **Email Integration**: Gmail SMTP (noreply email system)
